# 🎯 Holiday Practice (Java)

A collection of Java programs built using **IntelliJ IDEA** to practice and strengthen core programming concepts through small, practical applications.

---

## 🚀 Overview

This repository contains multiple beginner-to-intermediate Java programs focused on solving real-world problems and improving problem-solving skills.

---

## 📚 Topics Covered

* 🔁 Loops
* 🔀 Conditionals
* 📦 Arrays
* 🧩 Methods
* 🧠 Basic problem-solving techniques

---

## 🧪 Practice Projects

* 🎬 Movie Ticket System
* 💳 Mobile Wallet Simulation
* 🍕 Pizza Ordering System

Each program demonstrates how core Java concepts can be applied to build simple, functional systems.

---

## 🛠️ Technologies Used

* Java (Core Java)
* IntelliJ IDEA

---

## 🎯 Learning Objectives

* Improve understanding of Java fundamentals
* Practice writing clean and structured code
* Build confidence in solving real-world problems
* Strengthen logic and algorithmic thinking

---

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/FelixAluchio/holiday-practice.git
   ```

2. Open the project in IntelliJ IDEA

3. Run any `.java` file individually
